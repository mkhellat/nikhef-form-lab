# nikhef-form-lab

A collection of codes motivated by the nikhef-form open courses
published in https://www.nikhef.nl/~form/maindir/courses/.

[01-mc-integration-stratified](01-mc-integration-stratified) - 1-D
Monte-Carlo integration using startified sampling

[02-mc-integration-vegas](02-mc-integration-vegas) - 1-D Monte-Carlo
integration using 1978 version of VEGAS algorithm

[02S-sample-vegas-pipeline](02S-sample-vegas-pipeline) - a sample
pipeline for VEGAS multi-dimensional integratopn

[03-cs-e-e+_mu-mu+](03-cs-e-e+_mu-mu+) - calculation of $e^- e^+ \to \mu^- \mu^+$ scattering

[04-cs-e-e+_e-e+](04-cs-e-e+_e-e+) - calculation of $e^- e^+ \to e^- e^+$ scattering with a modified version performing variance reduction
using mapping techniques
