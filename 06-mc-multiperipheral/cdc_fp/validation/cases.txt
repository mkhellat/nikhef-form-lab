# CDC-60 oracle cases, version 1.
#
# Ids are at most 7 characters so an FTN5 program can use the same
# names. lit values are exact in a 48-bit integer coefficient.
# +0 and -0 are signed zeros. muln A B N is N truncating multiplies
# of A by B, not the Fortran ** operator.
#
# Seeded integers use the glibc LCG
#   s = (1103515245 * s + 12345) mod 2^31
# starting at s = 20261124. Each operand is (s mod 48) + 1.
# Four pairs are written out as lit lines so the Fortran side sees
# the same decimal integers. compare_cdc_oracle.py --check-cases
# recomputes them.
